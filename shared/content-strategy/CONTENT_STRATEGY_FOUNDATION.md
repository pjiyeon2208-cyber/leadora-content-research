# 콘텐츠 전략 기준 문서 (Content Strategy Foundation)

> 이 문서는 LEADORA와 우주선가 콘텐츠 전략의 **기준 문서**입니다.
> 새 콘텐츠 기획, 기존 글 보강, 유튜브 전환, SEO 조치를 결정할 때 이 문서를 먼저 참조합니다.
> 기준이 바뀌면 이 문서를 수정하고, 변경 이유를 `shared/decision-log/`에 기록합니다.
>
> 최초 작성: 2026-10-12

---

## 1. LEADORA 사업 내 우주선가의 위치

- **LEADORA**는 전체 사업 및 교육 브랜드입니다.
- **우주선가**는 LEADORA 사업의 주요 상품/콘텐츠 축 중 하나입니다.
- 우주선가는 별도의 독립 브랜드가 아니라, LEADORA 사업 안에서 **알아차림과 수행을 담당하는 축**입니다.
- 운영 채널: LEADORA는 Blogger, 우주선가는 네이버 블로그. 채널은 다르지만 하나의 콘텐츠 시스템으로 관리합니다.

LEADORA 핵심 철학:

> “세상이 나를 함부로 대하더라도,
> 나까지 나를 함부로 대하지 않는 법.”

## 2. 우주선가와 LEADORA의 역할 차이

| 구분 | 우주선가 | LEADORA |
| --- | --- | --- |
| 역할 | 알아차림 / 수행 / 내면 관찰 / 깊은 자기이해 | 알아차린 뒤의 선택 / 행동 / 현실 적용 / 자기주도권 |
| 주요 주제 | 명상, 수행, 알아차림, 송과체, 위빠사나, 몸과 마음 관찰, 직관과 분별, 차크라, 정기신, 자비심, 수행을 통한 깊은 자기이해 | 자기이해, 자기주도권, 선택, 행동, 감정, 관계, 경계, 직장 문제, 평가와 인정, 행동 변화, AI 시대의 셀프리더십 |
| 독자가 얻는 것 | 나를 있는 그대로 보는 힘 | 본 것을 바탕으로 현실에서 움직이는 힘 |
| 방법론상 중심 | AWARE | ENVISION → ACT → BLOOM |

## 3. 두 축의 연결 구조

공통 연결축:

> “알아차림은 자기 자신을 함부로 다루지 않는 연습이기도 합니다.”

이 문장을 두 축의 철학적 연결축으로 삼습니다.

```
우주선가                           LEADORA
알아차림 · 수행 · 내면 관찰   ──▶   선택 · 행동 · 현실 적용 · 자기주도권
        │                                   │
        └──── 나를 함부로 다루지 않는 연습 ────┘
              (AWARE → ENVISION → ACT → BLOOM)
```

연결 방식:

- **우주선가 → LEADORA**: 수행과 관찰로 알게 된 것을 일상·관계·직장에서 어떻게 선택과 행동으로 옮기는가.
- **LEADORA → 우주선가**: 선택과 행동이 흔들릴 때, 그 아래의 감정·몸·마음을 깊이 들여다보는 길.
- **브리지 콘텐츠**: 두 축을 한 글 안에서 잇는 콘텐츠. 연결축 문장을 중심으로 기획하며, 관련 기획은 `shared/brand-bridge/`에 둡니다.

## 4. 원천 콘텐츠 우선 전략

- **원천 콘텐츠**: 브랜드의 핵심 질문에 답하고, 검색형 글·영상·강의가 반복해서 참조하는 기준 글.
- **검색형/파생 콘텐츠**: 특정 검색 의도에 답하며 원천 콘텐츠로 독자를 연결하는 글.

원칙:

1. 원천 콘텐츠를 먼저 만들고, 검색형 글과 영상은 원천 콘텐츠에서 파생합니다.
2. 하나의 원천 콘텐츠는 하나의 핵심 질문에 답합니다.
3. 원천 콘텐츠는 `templates/source-content-template.md`로 기획하고 각 브랜드의 `source-content/`에 보관합니다.
4. **우주선가**: 2026년 11월까지의 발행 기획은 이미 확정되어 있으며 **재설계하지 않습니다**. 우주선가 작업은 실행, 품질관리, 구조화, 영상 재활용을 우선합니다.
5. **LEADORA**: 기존 발행글과 예약발행글을 먼저 분석한 뒤, 중복되지 않는 원천 콘텐츠를 정합니다.

## 5. 블로그 → 유튜브 확장 전략

- 블로그와 유튜브는 별도 작업이 아니라 **하나의 콘텐츠 시스템**입니다.
- 순서: 블로그 원천 콘텐츠 → 유튜브 롱폼(5~10분) → 쇼츠 2~5개 파생.
- 영상은 블로그를 읽어주는 것이 아니라, 사례·시연·말투·시각 자료 등 **영상에서만 줄 수 있는 요소**를 더합니다.
- 영상 설명란과 블로그 본문이 서로를 연결합니다.
- 전환 기획은 `templates/youtube-conversion-template.md`로 작성하고 각 브랜드의 `youtube/`에 보관합니다. 채널 차원의 전략은 `shared/youtube-strategy/`에 둡니다.

## 6. 새 글을 만들기 전 확인할 기준

새 콘텐츠를 만들기 전 **반드시** 다음 질문을 던집니다.

- [ ] 이미 비슷한 글이 있는가?
- [ ] 우주선가와 LEADORA 중 어느 축의 글인가?
- [ ] 두 축을 잇는 브리지 콘텐츠인가?
- [ ] 장기적으로 소유할 가치가 있는가?
- [ ] 검색 유입 역할이 있는가?
- [ ] 유튜브로 확장할 가치가 있는가?
- [ ] 기존 글을 보강하는 편이 새 글보다 나은가?

이 질문 중 답할 수 없는 항목이 있으면 “미확인”으로 적고, 필요한 데이터를 먼저 확보합니다.

## 7. 기존 콘텐츠와 중복 여부 확인 원칙

1. 새 주제를 정하기 전에 `shared/content-strategy/CONTENT_MAP_STATUS.md`와 각 브랜드의 `published-content/`, `scheduled-content/`를 확인합니다.
2. **핵심 질문**과 **검색 의도**가 같으면 제목이 달라도 중복으로 봅니다.
3. Search Console 데이터가 있으면, 같은 검색어에 여러 페이지가 노출되는지(카니발라이제이션) 확인합니다.
4. 중복이 의심되면 새 글 대신 **보강 / 통합 / 내부링크 연결** 중 하나를 먼저 검토합니다.
5. 우주선가와 LEADORA가 같은 주제를 다룰 때는 각 축의 역할(알아차림 vs 선택·행동)로 관점을 분리합니다. 관점이 분리되지 않으면 중복입니다.

## 8. 검색 유입과 브랜드 철학의 균형

- 검색 유입은 **독자를 만나는 입구**이고, 브랜드 철학은 **독자가 머무는 이유**입니다.
- 검색어만 좇아 철학과 무관한 글을 늘리지 않습니다.
- 반대로 철학적 글이라도 독자가 실제로 쓰는 말(검색어)로 제목과 도입을 씁니다.
- 검색형 글은 반드시 관련 원천 콘텐츠로 연결되어야 합니다.
- 판단은 실제 검색 데이터가 있을 때 데이터 기반으로 하며, 데이터가 없으면 [추정]으로 명시합니다.

## 9. 장기 콘텐츠 자산의 정의

다음 조건을 충족하는 콘텐츠를 장기 자산으로 봅니다.

1. **시간이 지나도 유효하다** — 유행·이슈에 의존하지 않는다.
2. **브랜드 철학을 대표한다** — LEADORA 핵심 철학 또는 연결축과 직접 연결된다.
3. **기준점 역할을 한다** — 다른 글·영상이 반복해서 참조한다.
4. **확장 가능하다** — 유튜브, 강의, 프로그램, 책으로 이어질 수 있다.
5. **중복되지 않는다** — 같은 질문에 답하는 다른 글이 없다.

새 글 수보다 장기 자산 가치를 우선합니다.

| 7 | 두 축의 역할을 섞지 않되, 연결축으로 잇는다. |
